# Sociology of Contemporary Analytic Philosophy — Case Study

R analysis for a case study on productivity, informal collaboration, and 
prestige (mentions) among philosophers and institutions, based on 
acknowledgment and authorship data from five analytic philosophy journals 
(2005–2019).

## Contents
- `Supplementary_materials.R` — full commented R script with all analyses
- `Acknowledgments_documentation.zip` — raw data used in the analysis
- `femp_project.pptx` — project presentation slides
